# MaxAgent 產品需求（PRD）

MaxAgent 是 Windows 桌面工作台，供同時使用多個 Agent Harness 的人管理既有對話。使用者在同一個程式查看任務、續派和收取結果，不必逐一打開原工具。

## 基本版交付門檻

使用者打開正式 MaxAgent，分別選擇一個 Codex 和一個 Claude Code 的既有聊天室，查看歷史並追加正常任務。任務送到所選的原聊天室，沿用前文；完成後在 MaxAgent 的同一對話看到新結果。不得另開或複製聊天室來替代。結果未讀與任務執行狀態分開，查看結果後清除未讀。交付以使用者實際操作為準。

- **Codex 派工可用：** 安裝了 Codex 桌面版但未把它的執行檔加入系統搜尋路徑時，MaxAgent 仍應能找到相容執行檔，或在設定明確引導選擇及檢查路徑。執行檔、工作目錄或權限出錯時要分開說明。
- **原工具畫面同步：** 從 MaxAgent 向既有對話派工後，使用者希望已開啟的 Codex／Claude Code 原對話即時顯示這次的新訊息和回覆。分開確認「原紀錄已保存」和「原視窗不重開就顯示」；若工具沒有支援後者，明確標示限制，提供在原工具重開同一個舊對話後確認的方式。MaxAgent 自己重新讀取原紀錄是輔助功能，不能取代原視窗同步。

## 已提出的產品目標

1. **卡片總覽：** 以舊看板為參考，讓使用者瀏覽所有可讀取的聊天室。卡片是唯一的聊天室選擇入口；總覽使用全寬，不保留左側聊天室列表或固定側欄。搜尋、篩選放在總覽頂部。卡片顯示名稱、簡介、工具及狀態；點卡片進入獨立對話頁，返回時保留瀏覽位置。只呈現可辨識的對話內容，系統附帶資料不得充當標題或訊息。未讀卡片以獨立的「● 未讀」徽章呈現，總覽有同樣符號的圖例；可在亮／暗模式辨認，不與執行或完成狀態混用。
2. **逐聊天室模型：** 可以在個別聊天室選擇目前工具或連線提供的模型和推理強度；MaxAgent 啟動時查詢，進入對話或手動刷新時更新。清單來源和帳號使用權限未確認需明示；工具拒絕時不換模型或重送。不支援時明確說明；逐聊天室 API Key／連線設定是產品方向，依 Harness 能力決定，不能改寫共用設定來冒充隔離。
3. **可選桌面寵物：** 使用者可開關寵物，透過它看到目前哪些聊天室在工作、哪些任務剛完成。
4. **可選 Windows 通知：** 開啟後，聊天室任務成功完成時由 Windows 顯示通知；關閉後不彈出。點通知跳轉不是要求。
5. **桌面介面：** 科技風、簡約，提供亮／暗模式，由使用者切換。聊天室參考 Codex：使用者訊息靠右、藍底白字；AI 正式回覆靠左，沒有對話泡泡底色，按 Markdown 格式呈現標題、列表、表格和程式碼等。使用者訊息維持原文；不執行回覆內嵌網頁標記、不自動載入圖片。工具公開顯示的處理進度保留，使用較淡但清楚的文字及「處理進度」標籤，和「正式回覆」分開；來源分不清楚時標為一般「AI 訊息」，不猜、不顯示內部推理欄位。
6. **效能與維護：** 降低清單刷新所需時間與記憶體，避免反覆讀取未改變的完整歷史；用同一批資料比較前後。保留可用功能，逐步簡化程式。
7. **更多 Harness：** 除 Codex、Claude Code，候選包括 DeepSeek Harness、OpenCode、WorkBuddy。各工具分開確認可讀歷史、可續聊、可辨識完成；只能讀取的標為唯讀。

## 後續方向

手機端經安全配對後可看結果及遠端派工，任務仍由電腦執行；憑證留在電腦。總指揮 Agent 可代派是後續方向。這些與寵物、逐聊天室模型及更多 Harness 不阻擋基本版交付。版本排序見[實作計劃](02-實作計劃.md)。
