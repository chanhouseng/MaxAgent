- 本機 `codex app-server proxy --help` 顯示它將 stdio 位元組轉送到指定 Unix socket；文件說該 socket 使用 WebSocket HTTP Upgrade。T3 0.166.0 報告 proxy 需要 JSONL ↔ WebSocket 橋；0.167.0-alpha.3.2 的實際 proxy 協定格式未能確認：用臨時目錄建立假 Unix socket 時 Windows 回 EACCES，連握手都未發生。沒有伺服器可連、沒有觀察到格式不相容；不能把理論文件或舊版本案例寫成本機格式實測。
